# Commercial product programme

Status: active internal programme, started 2026-08-10.

The owner has set a new target: turn the existing SMC decision-support system
into a commercial product with external users. These documents define the
current truth and the gates required to reach that target. They are internal
planning and governance documents, not customer-facing copy and not evidence
that the product has launched.

## Boundary

- The external commercial-clearance process is handled outside this repository.
- This repository records only whether its opaque owner-controlled gate has
  passed, never the process inputs, reasoning or conclusions.
- No document here is legal advice or an authorization to publish, market or
  sell the product.
