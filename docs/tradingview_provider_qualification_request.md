# TradingView provider-qualification routing request

**Submission status:** Ready for the authenticated TradingView support chatbot;

**Subject:** Routing request: data-provider onboarding for Pine-readable derived series

## Message

Hello TradingView team,

We operate Skipp, a decision-support product that produces derived numeric time
series for US equities. We would like to determine whether these series can be
qualified as an official TradingView data/content-provider integration.

Our required end state is that approved series are hosted in TradingView's own
data infrastructure, are discoverable on tradingview.com, and can be consumed
from Pine through a documented API and symbol model. This is not an Advanced
Charts Datafeed API request for a self-hosted chart, and it is not a broker
integration request.

Could you please route this inquiry to the team responsible for market-data or
content-provider onboarding and confirm:

1. whether derived, non-price numeric series are eligible for onboarding;
2. whether accepted series can be available on tradingview.com and read by Pine;
3. which partner, commercial, licensing and technical qualification process
   applies; and
4. what non-confidential information you need for an initial assessment?

We have prepared a small proposed pilot covering three US equities, three
15-minute derived series and limited history. We will provide the detailed data
dictionary, formulas, source contracts, rights attestations, samples and
operational design only through the appropriate partner process and under any
required confidentiality terms. We will not send or redistribute TradingView
content as part of the proposed feed.

Thank you.
